# FC 27 经理模式傻瓜包

为 FC 27 经理模式制作一个操作简单、说明清晰的整合包，让玩家更方便地完成配置和使用。

**当前阶段：项目初始化。** 尚未实现安装器、游戏适配或任何 MOD 功能，也尚未验证游戏兼容性。

## 项目方向

- 整理经理模式所需的功能、资源和配置。
- 简化安装、配置和启动流程。
- 在涉及游戏文件或存档的操作前，提供备份与恢复方式。
- 提供清晰的使用说明和常见问题解答。

上述内容是后续规划，具体功能与实现方式将在需求确认后确定。
