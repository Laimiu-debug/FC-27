# FC27 管理器 0.2.0 · 离线研究版

- 首次启动可连接已有工作区或创建新工作区，Windows 启动偏好仅记住工作区位置。
- 中文设置向导可保存本机配置、检测 Steam 游戏目录并逐项检查研究输入；配置独立保存，不覆盖旧配置。
- 后台任务显示研究、编译、打包、验证和加载副本阶段；流水线报告记录每阶段耗时。
- 保存最近 50 项任务；重启后将未完成任务标为中断，不自动重试，历史预检不作为本次会话证明。
- 修复操作失败后状态刷新再次异常可能留下忙碌状态的问题；日志写入失败不会阻止任务收尾。
- 修复 Windows 8.3 短路径被误判为越界的问题；先拒绝目录链接，再比较规范路径，继续拒绝 local 根和游戏目录写入。
- 单模块研究提前筛选资产；单次操作内缓存按 SDK、共享类型、清单散列及完整 GUID 集绑定的静态类型解析，保留全部基线与索引校验。
- 可导出脱敏离线诊断，核对候选绑定报告并列出封装、profile、CAS 回退和未覆盖的验证范围。
- Windows CI 运行离线测试并打包 EXE；版本标签与程序版本一致时发布预发行 ZIP、SHA256 和构建清单。

本发行版不含游戏文件、研究样本、Oodle 或个人配置。首次配置仍需在本机提供合法取得的研究资料；新工作区创建成功不代表研究输入已齐备。

系统需要 WebView2 Runtime 与 .NET Framework 4.6.2 或更新版，EXE 已包含 Python。工具不启动游戏、不修改游戏安装目录。FC27 封装接受性、实际加载与比赛 AI 效果尚未验证；本轮不进行实机验证。
