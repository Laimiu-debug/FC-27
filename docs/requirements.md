# 首版需求记录

当前状态：前代玩法研究、FC27 离线工具链与 Windows 桌面管理器已形成首版。此文件区分已确定需求和仍待确认事项，不代表已验证玩法优化。

## 已确定

- 项目名称：FC 27 经理模式傻瓜包。
- 项目目标：简化经理模式相关功能、资源和配置的使用流程。
- 支持目标：PC 版 FC27，经理模式实际场上比赛的整体玩法与球员 AI。
- 用户于 2026-10-08 曾授权实机测试，随后明确要求停止实机验证、继续开发。当前继续离线工具链，候选仅输出到项目目录，不写入安装目录。未来安装修改需要候选、备份和恢复流程。
- 可以下载所需研究资料和工具，开展自有离线格式与编译组件开发。
- 首版玩法研究覆盖持球决策、无球接应、协同防守、角色职责和攻守转换。
- 候选模组需按具体游戏构建适配；离线检查与比赛效果验证分开记录。
- 交付形式已确定为带中文前端界面的 Windows EXE 管理器，已封装现有离线管理功能；游戏安装与实际加载能力仍待完成。
- 解析核心使用 Python 标准库，界面使用原生 HTML/CSS/JavaScript，桌面封装使用 pywebview 与 PyInstaller。
